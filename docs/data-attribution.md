# Catalog data and attribution

Orbis uses the TMDB API for movie and series identity, metadata and remotely
hosted artwork. Each installation supplies its own TMDB API key. Orbis includes
TMDB's approved mark and required non-endorsement notice in the in-app
Credits/data-sources view. See [TMDB's API terms](https://www.themoviedb.org/api-terms-of-use)
and [logo guidance](https://www.themoviedb.org/about/logos-attribution).
Downloaded posters and backdrops are fetched at runtime; they are not bundled
with this source repository or TV packages.

Optional IMDb dataset support is local and subject to IMDb's separate
[data-use rules](https://help.imdb.com/article/imdb/general-information/can-i-use-imdb-data-in-my-software/G5JTRESSHJBBHTGX).
Do not publish a populated catalog database or redistribute dataset exports
without checking those terms. Orbis does not imply TMDB or IMDb endorsement.
