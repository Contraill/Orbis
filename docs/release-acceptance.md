# Orbis V1 release acceptance

Run these short journeys before a release is accepted. Use the disposable browser fixture for first-run and deletion; never reset the live database. Use known-working installed media for playback. A journey passes only when its visible outcome works. Record any unavailable branch as partial with its reason.

| Journey | Setup and actions | Expected result | 2026-10-05 result |
| --- | --- | --- | --- |
| 1. First experience | Disposable empty database: open Orbis, choose Türkçe, create the first profile, customize its avatar, pick five favorites, finish. | English welcome, Turkish setup after selection, first profile is owner, avatar and five choices persist, Home opens. | PASS — isolated browser fixture. |
| 2. Profile household | In the fixture, add a viewer from Profile Picker, edit its preferences, switch profiles, then self-delete the viewer by typing its name. | Add lives on Picker, Manage lives inside the active profile; locales and avatars stay separate; viewer lacks Admin; owner cannot self-delete. | PASS — isolated browser fixture and product smoke. |
| 3. Discovery | With a populated catalog, inspect Home current popular and new releases; open a genre. Repeat on Movies and Series, including new seasons; scroll for two continuations each. | Semantic shelves and category links work; Home can mix movies/series, scoped pages do not; cursor batches append. | PASS — live browser, two continuation requests per surface. |
| 4. Search | Search an exact title, typo, person, company where available, and genre; open a result. Change All/Movies/Series scope for genre. | Localized/fuzzy results lead to the correct Detail/category; genre scope is retained. | PASS — live exact/typo/person/company/genre, scoped Action links and Detail. |
| 5. Detail and trailer | Open a title with a trailer on desktop and at 390px; let it play, reveal/hide details, toggle My List and reverse it. | Trailer dominates, metadata/actions recede, details return, no mobile overflow. | PASS — live Interstellar trailer and reversible My List toggle. |
| 6. Standalone playback | Play a known-working episode outside a room; test pause/play, ±10, timeline, fullscreen, Quality/Audio/Subtitles, Back. On a two-audio title switch Turkish → Original → Turkish. | Video frames and time advance; controls act on media; original runtime audio changes; consumer has no Provider/Source controls; progress persists. | PASS — live Lanterns and Bad Boys II; cropped 1920×802 displays 1080p. |
| 7. Series continuity | From series Detail start/resume an episode, open Episodes, choose another and return. | Canonical episode route changes, new media resolves, Back returns to series Detail. | PASS — live Lanterns episode 4 → episode 1. Autoplay-next remains fixture-tested. |
| 8. Watch Together | Two profiles/contexts: create/join a six-digit room, refresh one, start an episode, verify both videos advance, then pause/resume and seek in both directions. Leave in sequence. | One membership after refresh; both decode/advance; peer commands converge; first leaver does not close the room. | PASS — live Can/Zey contexts, decoded frames and bidirectional commands. |
| 9. Shared versus local | In a room, change subtitle/audio/quality on one participant while checking the other's selection and canonical room state. | Content/play/timeline are shared; Provider/Source/Quality/Audio/Subtitles remain local. | PASS — USER-VERIFIED LIVE: different participants used different audio languages and subtitle settings while shared playback stayed synchronized. |
| 10. Admin boundary | Owner opens Admin and, if password is available, signs in to Provider Settings; viewer attempts the direct route/API. | Owner entry/auth works and secrets stay masked; viewer cannot gain authority. | PASS — authenticated owner opened Provider Settings and ran a real episode source diagnostic; quality, audio, subtitle and ranking metadata appeared without secrets or stream URLs. Viewer UI blocked; Admin API returned 401. |
| 11. Mobile core | At 390×844: select profile → Home → Search → Detail → playback → Back → Watch Together panel. | Labeled room action, profile identity, bottom navigation and player controls fit without horizontal overflow. | PASS — live mobile browser. |
| 12. Returning user | Select a profile with existing history, use Continue Watching, resume a series. | Correct episode starts near saved position and advances. | PASS — live Lanterns S01E04 resumed near 138 seconds. |

For audio acceptance, inspect Shaka's **active** runtime rendition after each change; a selected menu item alone is insufficient. For Watch Together, require `readyState >= 2`, decoded frames, advancing `currentTime` on both clients, and bidirectional pause/seek convergence. Do not use navigation to `/watch` as playback proof.
